# Optional owned volume chunk-cache writes

`VolumeChunkCache(..., owned_writes=True)` connects fresh ownership and atomic non-clobber publication to the existing backend NPZ cache store. The new option is a strict boolean and defaults to `False`. Default writes retain their existing exact-key overwrite behavior, return values, deterministic paths, payload fields and statistics. Cache reads are unchanged. The renderer's intentional exact-path `save_render` contract, reports and other backend producers are unchanged.

In the opt-in route, a store creates only a fresh `.cache-runs/owned-*` directory beneath the namespace directory. It writes `chunk.npz`, verifies the closed stage through NPZ/header checks and byte-exact data/metadata round trips, and links it atomically to the same deterministic `digest.npz` path. The first successful write retains normal `True`/writes/bytes-written semantics. A same-key collision never replaces the previous file or chooses a different cache key: it returns `False`, increments `write_errors`, and preserves the verified failed stage and failure receipt. A serialization or publication failure similarly retains new diagnostics without changing earlier results or caller arrays/metadata. Inputs are not adopted as owned artifacts.

`cache.last_ownership_receipt` points to the latest fresh opt-in attempt's `cache-store.json`, including failed attempts. It is `None` when validation fails before ownership creation. Each receipt records input shape/dtype, uncompressed array and metadata byte counts, metadata hash, stage byte bound, bounded verification reads, requested/published path, byte hash and collision/failure state. The original bool return API and statistics schema remain intact. A post-publication receipt error can return `False` even when the cache entry was already published; the ownership manifest retains that final path/hash binding and the failed receipt history. No prior cache entry is adopted or overwritten by this opt-in producer.

## Bounds and ownership scope

Before copying or serializing, opt-in data must be a three-dimensional non-object array with at most 64 MiB of uncompressed array storage, and serialized metadata must be at most 1 MiB of UTF-8 bytes. Metadata's NumPy Unicode storage can be larger and is accounted separately. This is an uncompressed-input limit, not a claim that a small compressed file permits an arbitrarily large array. The deterministic key filename must be exactly a lowercase 64-character SHA256 plus `.npz`.

The stage writer limits file positions and every actual write to `2 * array.nbytes + metadata_array.nbytes + 65536`. Verification reads also enforce position and cumulative read bounds, allowing at most one extra byte before a breach is rejected. NPZ member count/names, uncompressed sizes, NPY header limits, shape, dtype and object prohibition are checked before allocating loaded arrays. Generated headers must use NPY version 1 or 2. A tiny compressed archive declaring giant dimensions is rejected before `np.load`. The stage is then loaded with pickle disabled, and restored values/metadata must match the bounded snapshot.

The existing `OwnedRun` registration budget adds receipt headroom and checks actual registered bytes; it is separate from the strict stage stream bound. Stages and receipts are retained, including known partials. This producer is synchronous and starts zero subprocesses, so it closes only after serialization/verification/publication returns or raises. It owns none of the backend's other processes, shared caches, historical files or caller inputs. Interrupted writes preserve cancellation history. No deletion, reclamation, crash recovery, installation, ACL change or historical ownership adoption is performed.

Publication requires hard-link support on the destination filesystem. Unsupported publication is an explicit failed store with retained staging. Hard links share bytes; later external mutation can cause recorded hash audits to fail, and no security freeze is claimed. Callers can choose `owned_writes=True` directly; no backend default or active quality experiment was changed.
