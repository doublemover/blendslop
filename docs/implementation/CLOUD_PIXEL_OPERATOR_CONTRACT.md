# Extracted-field pixel support and separately identified raster tracks

This checkpoint fixes a concrete proposal-objective mismatch without replacing
public ranking or historical scores. The optional original-pixel extracted-mesh
objective and canonical diagnostic metric require explicit selection. The existing
minimum-distance objective and public legacy PIL score remain available unchanged.
Native input/render filter acceptance is still unrun under repository instructions.

## Isolated causes on one existing observation

The fixed thin-plate/hole observation was originally generated by the legacy PIL
source projector. It is synthetic and is not a held-out/native-render benchmark.
Its evidence and camera remain fixed during this analysis; no mask is regenerated
with another rasterizer to make a result look better.

On the legacy track, the source scores 0.950617, extracting the unconditioned field
scores 0.939643, feasibility conditioning alone scores 0.940934, and 16 min-SDF
updates score 0.908488. Extraction loses eight observed foreground pixels before
conditioning or optimization. Separately, optimization lowers its surrogate loss
from 0.006734 to 0.002240 while worsening actual legacy opaque support.

The new original-pixel extracted-mesh objective scores 0.898701 on that same
legacy track. On the separately identified half-cell-area track, the same source
scores 0.876543 and the proposed mesh scores 0.954103. These numbers must never
be compared across raster identities. Both optimized proposals still fill 25%
of the known-hole core, above the unchanged 10% feature limit, and native boundary
qualification is unavailable. They are not accepted reconstructions. Public
ranking still reports the selected geometry's legacy score, even when an explicit
canonical admission experiment is requested.

## Actual objective implementation

Each forward pass extracts the current signed-field zero set using the same
scikit-image 0.26 Lewiner policy as saved-field output. Supported active grid-edge
vertices are rebuilt as differentiable interpolation of their two field samples.
Unsupported interior/exact-grid carriers or excessive triangle counts fail
explicitly, retaining an earlier finite scored checkpoint when available. Active
marching and projected-union topology is recomputed each evaluation; its derivative
is local to that active topology, not a smooth guarantee across topology changes.

The projected triangle union uses the existing vertex/intersection carriers and
pinned DVX 0.1.1 CPU closed-form 2D box support. The original camera pixel size is
preserved. Non-square images are embedded in a square support with unknown,
zero-weight padding; no image resampling or camera rebounding occurs. Original
validity, probability, confidence and boundary-reliability arrays are retained.
Unknown samples do not enter the objective or final comparisons. The residual
world-value bounds, source and exact-contact guards remain unchanged.

The official coordinate/layout and filter conventions are documented by the
[DVX implementation](https://github.com/mworchel/differentiable-voxelization#conventions-for-coordinates-and-data-layout)
and its [Torch wrapper](https://github.com/mworchel/differentiable-voxelization/blob/main/dvx/torch/voxelize.py).
They describe ideal opaque uniform-box coverage, not the actual native renderer's
sampling/filter policy.

## Pixel conventions and retained evidence

The canonical camera mapping expresses integer pixel-center coordinates. A pixel
cell therefore spans center ±0.5. Independent analytic rectangles and triangles
at integer and half-pixel boundaries distinguish inclusive center hits, half-area
classification and PIL endpoint rounding. A four-by-four cell-edge rectangle has
16 center/area pixels, while legacy PIL draws 25. Integer corner cells can have
quarter coverage despite an inclusive center hit, so center sampling and half-area
classification are also separately identified.

For synthetic RGBA alpha generated from analytic coverage, the actual target
extraction retains the rounded alpha probability and thresholds it at >127/255.
An independent test verifies the resulting half-area mask and the retained
continuous probability-weighted coverage error. The continuous comparison is
reported alongside binary IoU; it does not discard alpha to match a threshold.
Grayscale likelihood maps are explicitly not asserted to be measured alpha
coverage. Real native anti-aliasing, alpha/filter settings and source images still
require the prepared renderer-contract check.

## Saved follow-through

The validator packages frozen reference, source, unconditioned field extraction,
conditioning-only, min-distance optimization and original-pixel mesh optimization.
Every stage saves geometry, field/world transforms when applicable, raw continuous
coverage, both binary canonical masks, the legacy mask, original probability,
validity/reliability arrays and independently identified scores. Analytic edge
counterexamples, raw alpha arrays and a source/proposal mask comparison are saved
alongside the packet. A later native check can render the exact unchanged source
and proposals with the original camera/filter/alpha settings and compare these
arrays directly instead of relying on ambiguous score claims.

Actual bounded pinned checks cover field-edge derivatives, 16/32 anisotropic
cell-center reconstruction, original-pixel coverage against independent polygon
cell intersections, projected-objective pullbacks, unknown probability exclusion
and safe retention after an unsupported later extraction event. No broad timing
campaign, external dataset, Windows/native Blender acceptance or generalized
reconstruction-quality/speed gain is claimed.

Final focused evidence for this checkpoint: 143 host CPU tests across 16 suites,
16 actual pinned numerical tests (overlapping the earlier nine foundation checks),
607 parsed Python files, three retained-output integration jobs and the five-stage
fixed-observation diagnostic. Exact contact/fold regressions remain in the host
scope. These counts describe their scopes; they are not independent quality-case
counts or a native acceptance total.
