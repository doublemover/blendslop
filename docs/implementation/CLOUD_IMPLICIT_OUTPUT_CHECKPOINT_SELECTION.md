# N2 evaluated fields ranked on original-camera output

The numerical helper can retain at most 17 finite fields that actually received
an objective evaluation. The optional backend checkpoint selector ranks their
extracted meshes on the declared original-camera opaque metric. Default public
ranking retains the existing legacy PIL identity; explicitly configured half-area
projection remains a separately identified track. Surrogate loss does not select
the final proposed mesh when this selector is enabled. The source remains the
backend retention candidate and artist/source artifacts remain separate.

Each checkpoint has a strict five-field record, unique bounded evaluation ID,
loss matching its recorded evaluated history, finite residual coordinates,
matching coordinate-decoded field, evidence/constraint identity, content digest,
and unchanged world displacement/protected-empty bounds. Unevaluated optimizer
updates cannot enter the pool. A shared extraction/projection allowance retains
an already scored prefix; exhaustion before any extracted score fails closed.

Ordering first prefers the existing preliminary original-output requirements:
closed/oriented structural screen, per-view success, observed known-empty feature
checks, no additional certain-empty pixels, and the existing area/boundary
improvement tolerances. It then compares minimum/mean area and boundary scores.
This is ordering only: the selected proposal still requires the unchanged exact
finite-mesh boundary check and content-scoped native qualification. A positive
ordering result is not a native admission certificate. Unknown pixels remain
excluded through the existing ray and final projection evidence paths.

The saved field state retains the selected proposal plus every checkpoint field
actually scored on the opaque metric, its evaluation ID and surrogate total.
Source/proposal/retained meshes and final authoritative replay remain distinct.

The existing thin plate/observed-hole fixture illustrates the mismatch: legacy
source IoU is .950617; surrogate-best evaluation17 yields .908488; output-selected
evaluation14 yields .951389. None of these fields passes preliminary admission,
and the backend retains the actual source. This is an implementation fixture,
not a reconstruction quality gain, held-out evaluation or timing comparison.

New verification at this source: 34 focused host pipeline/pixel checks, 19 actual
pinned CPU numerical checks, and five owned-helper integration jobs at 16/32
including the existing through-hole and strictly separated assembly fixtures.
All five final paths retain their source and reproduce the proposed field mesh
through authoritative artifact replay. 609 Python files parse. Native rendering,

## Optional-proposal failure retains the source

After selection of a validated same-evidence source, an expired candidate budget,
missing pinned helper/operator, optional import failure, solver/transport error
or rejected helper identity returns that original geometry as a degraded result.
The existing source mesh/artist/artifact paths and metrics are retained, with the
output content hash and an explicit proposal-unavailable reason. This does not
qualify the source anew or treat the unavailable residual as a successful fit.
Approval/configuration rejection and absence of an admissible source still stop
before numerical work as before.

The affected host scope passes 60 checks, including corrupt proposal identity,
missing helper/import, expired budget without optimizer work, source artifact and
metric preservation, and existing backend behavior. Five actual pinned-helper
jobs pass with the final archive identity and complete checkpoint-coordinate/
mesh replay; all retain their source. 609 Python files parse. Native rendering,
real reconstruction quality and independent timing remain unmeasured.

## Exact boundary eligibility during checkpoint ordering

An output/evidence-eligible checkpoint now receives the unchanged exact
binary64/rational within-part boundary guard before it can displace a passed
checkpoint. The guard consumes the remaining shared selection allowance. An
unavailable later guard ends the scored prefix without displacing an earlier
passed candidate. Ineligible candidates remain available as labeled proposal
diagnostics; they cannot gain admission from this ordering.

47 affected host checks pass. A topologically closed, positive-volume cube with
a displaced vertex has an actual proper crossing under the exact predicate.
With explicitly mocked score ordering, its higher score cannot displace an
earlier safe cube, and an unverified later boundary timeout cannot do so either.
Those score mocks isolate candidate routing; they are not quality measurements.
The backend still runs its final exact boundary/content-native admission checks.
No tolerances or contact classification rules changed.

## Single-checkpoint validation and reproducible counterexample

The central field validator now checks strict bounded integer evaluation IDs,
objective count, finite numeric history, and loss correspondence even when output
checkpoint selection is explicitly disabled. Truthy strings/Booleans and a loss
unrelated to its history cannot qualify a helper field. Full-pool replay validates
the same recorded history as the live path.

The affected host scope passes 69 checks. The actual pinned helper reproduces
the earlier fixed32/16-update thin-hole counterexample: selected evaluation14
legacy IoU .951389, surrogate-best17 .908488, source .950617. All17 saved fields
replay to their recorded meshes and the actual source remains retained. The
separate default16 check gives .874189 for both the selected and surrogate-best
legacy masks; it uses a different grid/displacement bound and also retains source.
These are separately identified generated-reference operator fixtures, without
quality, timing or held-out claims.

and saves original probability/validity/reliability evidence, camera metadata,

Their evidence/geometry identities are recorded. The synthetic reference still
comes from legacy projection; no native filter convention is inferred. 610
Python files parse. Native renderer/filter and reconstruction acceptance remain
